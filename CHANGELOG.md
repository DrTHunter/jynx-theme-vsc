# Changelog

## 1.0.0

- Initial release of the Jynx (Arcane) dark theme.
- Full workbench UI theming (editor, sidebar, activity bar, status bar, tabs, terminal, git decorations).
- Syntax highlighting tuned to Jinx's palette: hot pink, electric blue, shimmer purple, gold, and neon green.
- Rainbow bracket pair colorization using the full palette.
